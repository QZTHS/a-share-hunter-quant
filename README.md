# A股猎手 Quant 1.0（原型）

这是一个可部署到云端的 Streamlit 网页原型，适合先用 iPhone 浏览器访问。

## 重要说明
- 当前页面中的股票名称、代码、行情与指标全部是**模拟数据**，只用于验证界面。
- 目前没有连接真实行情数据源，也没有真实回测结果。
- 请勿根据演示数据进行交易。

## 文件
- `app.py`：网页主程序
- `requirements.txt`：部署依赖
- `README.md`：说明

## 推荐部署路径（手机也可尝试）
1. 在 GitHub 创建一个新仓库，例如 `a-share-hunter-quant`。
2. 把本项目中的三个文件上传到仓库根目录。
3. 在 Streamlit Community Cloud 登录并授权 GitHub。
4. 选择该仓库，主文件填 `app.py`，点击 Deploy。
5. 部署完成后，保存网页地址到 iPhone 主屏幕。

如果手机网页端上传文件不方便，可以先在 iPhone 的“文件”App 中解压 ZIP，再通过 GitHub 网页版上传文件。不同平台界面可能变化。

## 下一阶段开发顺序
1. 选择并验证真实A股日线数据源，明确接口可用性、限频、复权方式与数据覆盖。
2. 建立全市场证券列表与日线数据缓存。
3. 实现三套透明选股规则：超短线、短波段、中线趋势。
4. 加入交易费用、滑点、涨跌停无法成交、停牌和披露时点约束。
5. 用滚动样本外测试验证策略，避免未来函数和幸存者偏差。

## 本地运行（如果以后有电脑）
```bash
pip install -r requirements.txt
streamlit run app.py
```
